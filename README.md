# Pet Healthcare System

## Project Overview
A web-based Pet Healthcare System designed to help manage pet health information and support veterinary healthcare services.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Key Features
- Pet information management.
- Pet health record management.
- Veterinary information management.
- Appointment management.
- User-friendly interface.

## Project Objectives
- Simplify pet healthcare management.
- Maintain organised pet health records.
- Support veterinary service management.
- Apply web development and database management skills.

## Repository Contents
This repository contains the project source code, database files, web pages and related resources.
